Was ist Facta Falsa?

Facta Falsa hilft dabei, Behauptungen mithilfe veröffentlichter Faktenchecks zu überprüfen. Die Browser-Erweiterung nutzt die Google Fact Check Tools API und zeigt passende Faktenchecks von vertrauenswürdigen Quellen an.

Browser-Erweiterung

Markiere Text auf einer Webseite und prüfe ihn direkt mit Facta Falsa. Durch eine Erweiterung kannst du Facta Falsa in Chrome oder Edge ohne eine seperate Website benutzen.
